# 板件定义规则

回答“有哪些实体家具部件？”；位于已确认布局后、制造/特征树前。板件是实体板，不是 CAD 实体；本阶段只读取布局投影出的柜体包络，不读取房间几何。

## 记录

柜体是父对象。板件先属于某一子装配，再属于该柜体实例：`carcass` 承载围合体、层板、背拉条和一体化踢脚板；`fronts` 承载门板；每个抽屉是 `drawers[]` 里的子装配，当前五件盒（前/侧/后/底）写在 `box.panels`。常见柜内角色：左右侧板、顶/底/背板、层/隔板、门/抽屉面、横撑和踢脚板。每块记录所属柜体 `parent_id`、所属子装配 `assembly_id`、柜内角色 `role`、全局标识 `id`（`{cabinet_id}__{role}`）、成品尺寸、相对柜体原点的位置和朝向。接触写在所属子装配上：一条接触是大面被端面顶住。

## 板件规则

- 柜型拓扑骨架归本阶段 `references/cabinet-topologies/`：YAML 只声明围合面、
  语义面、有无踢脚、抽屉区类型。门板等分、层板累加、抽屉尺寸链和三种
  背板几何由求解器执行；不能只加 YAML 就支持新柜型。已确认外形尺寸只记录
  `furniture_category` 与宽深高，不得承载板件构成或板件面关系。
- 用角色及其与外形尺寸/区域的关系表达板件；位置用最小角点、包络、面或板件关系。
- 层板和隔板不得与选定的背板结构冲突；层板列表语义、计算层和固定/活动层板物化见
  [层板规则](shelf-planning-rules.md)。
- 中立板（`panel_type = divider`，柜内角色 `divider_1`）站在内部净空里：底面在底板上表面、
  顶面在顶板下表面，**深度从柜背（`carcass_y_start`）做到内空前沿**——通到柜背是为了让每腔的
  背板和背拉条夹在板与板之间，见 [背板结构规则](back-construction-rules.md)。位置由评估器按
  「缝定锚」给（`construction_geometry.divider_panel_boxes`）。它**两张朝柜内的大面都接端面**——
  `inner_face` 之外多声明一张 `bearing_faces`，漏一张就少一侧的连接。顺纹沿高。
  有中立板时层板**按腔分段**出件（每腔一块，id 带腔序号 `shelf_c1_z*`），
  背板与背拉条同样按腔出件；没有中立板时层板 id 与几何和以前逐字节相同。
  当前边界：一台最多 `n_doors − 1` 块（缝数 = 门数 − 1）、通高、只有一排整高门、
  不与抽屉区共存。**落地面是后期选项**（坐底板 / 落地 / 坐在踢脚板上），今天只要求
  不挡路：立板的 z 范围只由 `divider_panel_boxes` 一处给，背板与背拉条不引用它，
  立板上的背板槽按「立板高度 ∩ 背板高度」裁，换落地面时背板这一侧不用改。
- 门板落在前开口净空包络内。**一整排门按扇序出件，扇数不再限制成 1/2**；每扇的宽度与起点
  只从评估器取（`construction_geometry.door_interior_report`），板件阶段不自己推导等分槽。
  角色名：一扇 `single_door`、两扇 `left_door`/`right_door`（老名字，冻结文件钉着）、
  三扇以上 `door_1…door_n`。门高仍是"柜高 − 踢脚 − 2×边距"，一排整高门。
  **铰链侧也是板件属性**（`door_hinge_side`）：对开腔由几何定（左 left、右 right），
  单开腔由提案的 `door_hinges` 给；**不给只报警告、不拦确认**——留空的那些在板件页上
  选左开/右开，或下一版补 `door_hinges`。制造才是硬闸门。规则见 [门板铰链侧](door-hinge-side.md)。
- `drawer_count>0` 的抽屉区可以是**整柜净高**、**一段显式净高**（`drawer_clear_height_mm` +
  `drawer_anchor`）或**层板切出的一格**（`drawer_bay_index`，1 = 最上面一格）。
  层板可以与抽屉共存，但共存时抽屉必须点名落在哪一格。抽屉跨整个内宽，所以还不能与
  中立板共存；门与抽屉也不能共用一张正面开口。混合分区的停问见
  [提案契约](panel-proposal-contract.md)。不得由代码按数量优先级静默丢弃任何区域。
  抽屉区尺寸链与板件构成见 [抽屉尺寸链](drawer-dimension-chain.md)。
- 抽屉每侧净空、层缝和后部净空分别来自已准入的
  `drawer_side_clearance/drawer_layer_gap/drawer_back_clearance`。
  抽屉前板、侧板、背板、底板与抽面的料厚走柜体板，见 [料档与工艺卡](sheet-stock-catalog.md)；
  有前板时一抽 6 块、没有前板时 5 块（`drawer_front_board`）。
- 背板结构、精确净空和三种模式尺寸统一按 [背板结构规则](back-construction-rules.md)；本文件不复制解析公式。
- 入槽背拉条夹在左右侧板之间；数量、等距布置和净距按
  [背板结构规则](back-construction-rules.md) 物化并校验，净距必须为正。
- 本阶段只定背板/背拉条尺寸、位置、依赖。
- 踢脚高度和前后退让在本阶段首次物化并形成精确区域；随后生成前后踢脚板和支撑板。
  数量公式、支撑净距和样例见 [踢脚规则](toe-kick-rules.md)。

## 边界

- 本阶段只产出板件尺寸、相对柜体原点的位置，以及板件之间的大面–端面关系。
- 材料、公差、连接和加工交给制造；建模依赖和 CAD 表达交给特征树。
