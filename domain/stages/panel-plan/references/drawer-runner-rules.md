# 抽屉滑轨系统规则

回答“抽屉用哪种轨、上下间隙多少、抽芯多深、底板要不要抬起？”；本文件是滑轨系统口径的唯一规则中心。[抽屉尺寸链](drawer-dimension-chain.md) 讲链条顺序，这里讲每个系统的数与查表。

**状态：三节轨与托底轨已落地**（`drawer_runner` + 抽芯档 + 后缝下限 + 轨腔高度 + 格高查表）；抽屉区可以只占一段**净高**（`drawer_clear_height_mm` + `drawer_anchor`），也可以落在**层板切出的一格**（`drawer_bay_index`）。独立抽面、骑马抽、水平并排还没做，见文末「未做」。

## 一、两个字段：滑轨系统口径 + 抽屉区的空间

### 滑轨系统（`drawer_runner`）

提案只需给 `drawer_runner`（缺省 `side_mount`，等于缺省时不落盘）。其余全部查表，**每侧间隙也可以省略**（省略按系统展开，显式写出则保持原值）：

| 口径 | 三节轨 side_mount | 托底轨 undermount |
| --- | --- | --- |
| 每侧间隙（抽盒 ↔ 柜体） | 13 | 6.5 |
| 抽芯深度档（不含抽面） | 200 / 250 / 300 / 350 / 400 / 450 / 500 | 240 / 290 / 340 / 390 / 440 / 490 |
| 后缝下限（必须**严格大于**） | 0 | 10 |
| 轨腔高度（底板底面 ↔ 盒体底面） | 0 | 11 |
| 格高 < 该值：空间过低（警告） | 70 | 80 |
| 格高 > 该值：空间过高（警告） | 260 | 不设上限 |

**档位先到 500 / 490 为止**：需要更深的抽盒时往 `depth_ladder_mm` 里加档即可（加数据，不改代码），盒深会自动取“放得下的最大一档”。

### 抽屉区的空间（`drawer_clear_height_mm` + `drawer_anchor`）

| 写法 | 空间 | 场景 |
| --- | --- | --- |
| 都不写（缺省） | 整个柜内净高，按抽数均分 | 整柜抽屉塔 |
| `clear_height`：给净高 + 贴哪一头 | 只占这一段 | 一个空间装一个抽、顶部薄抽、底部薄抽 |
| `bay`：给 `drawer_bay_index` | 层板切出来的第 k 格（1 = 最上面一格） | 层板之间加抽 |

- **净高是“表面到表面”**：上下两块板表面之间的距离，**不减板厚**。写成节距（中心线到中心线）会每层差一个板厚。层板切出来的格，格高直接取上层的 `gap_below_mm` / 顶格的 `top_gap_mm`。
- `drawer_anchor` 取 `bottom`（缺省，贴柜内底面）或 `top`（贴顶板下表面）；不给净高却写 anchor 直接拒。
- **层板与抽屉共存时必须给 `drawer_bay_index`**；`drawer_bay_index` 与 `drawer_clear_height_mm` 互斥。
- 净高 > 柜内净高、格号越界、或切出来的盒高 ≤ 0，都是几何错误，拦确认。
- 抽屉区之外的剩余空间：今天**不放任何东西**（除了层板本身）。

## 二、盒体构成（两条轨一样）

| 板件 | 位置 | 尺寸 |
| --- | --- | --- |
| 左右侧板 | 盒体外宽、全高、全深 | `板厚 × 盒深 × 盒高` |
| 背板 | **夹在两侧板之间**，底面与底板底面齐平 | `内宽 × 背板厚 × (盒高 − 轨腔)` |
| 前板（可能没有） | 同上，在盒前沿内侧 | `内宽 × 板厚 × (盒高 − 轨腔)` |
| 底板 | 夹在前板与背板之间，底面与它们齐平 | `内宽 × (盒深 − 背板厚 − 前板厚) × 底板厚` |
| 抽面 | 盒体之外、柜体前平面内 | 正面排版给（现在是格高减层缝） |

- 有前板 = **6 块**（前板 + 左右侧板 + 背板 + 底板 + 抽面）；没有前板 = **5 块**，抽面直接当盒体前墙。
- 托底轨的底板抬高 11，**前板与背板跟着一起抬**（三者底面齐平），侧板仍是全高——于是盒体后下方那道 11 的空腔四面封闭，轨藏在里面。

## 三、格高 → 上下间隙

区间**左开右闭**，按顺序匹配；超出最后一档按 20/20 处理（并报警告）。

| 格高 | 三节轨 下/上 | 托底轨 下/上 |
| --- | --- | --- |
| 70 ~ 130 | 10 / 10 | — |
| 130 ~ 220 | 10 / 20 | — |
| 80 ~ 220 | — | 20 / 10 |
| 220 ~ 260 | 20 / 20 | 20 / 20（>220 一律） |
| > 260 | 20 / 20（警告） | 20 / 20 |

## 四、盒高、盒深、后缝

```
格高   = 内部净高 ÷ 抽数
盒高′  = 格高 − 下间隙 − 上间隙
盒高   = 盒高′ 向下取到 10 的整数倍          # 车间要求盒高为 10 的倍数
余量   = 盒高′ − 盒高                        # 0..9，进上间隙
盒体 z = 格起点 + 下间隙
底板 z = 盒体 z + 轨腔高度

可装深度 = 内深 − 抽面厚（内嵌口径，抽面占一块板厚）
盒深     = 抽芯档里 满足「可装深度 − 盒深 > 后缝下限」的最大一档
后缝     = 可装深度 − 盒深                   # 结果，只会 ≥ 下限
```

**后缝是结果，不是输入。** 提案给的 `drawer_back_clearance` 是**最小要求**：准入只校验它大于该系统的下限；实际后缝由档位决定（取档后可能更大）。这样既不会出现“默认 0、抽屉贴柜背”，也不需要提案自己凑档位。

**取整余量进上间隙**：下间隙保持规范值，盒体不往轨上压。

## 五、样例（800×1000×600、板厚 18、3 抽、后缝要求 20）

| | 三节轨 | 托底轨 |
| --- | --- | --- |
| 格高 | 304.667 | 304.667 |
| 下 / 上间隙 | 20 / 24.667 | 20 / 24.667 |
| 盒高 | 260 | 260 |
| 盒深 / 后缝 | 500 / 35 | 490 / 45 |
| 底板、（前板、背板）底面 z（相对盒底） | 0 | +11 |

格高 304.667 超过三节轨的 260，所以这一台会带一条 `DRAWER_CELL_TOO_HIGH` 警告（不拦确认）；改成 4 抽就不会。

## 六、警告不拦

`DRAWER_CELL_TOO_LOW` / `DRAWER_CELL_TOO_HIGH` 是**警告**：写进校验报告、显示给人，但不拦确认。真正拦确认的是几何做不出来（盒高取整后 ≤ 0、底板 + 轨腔占满盒高、内深放不下任何一档抽芯）。

## 七、未做

1. **空间的最后一种**：水平并排（整排切宽），它要多一块中间竖板。
2. **不均分**：一个抽屉区里各抽等高；要“这抽 120、那抽 260”得加逐格尺寸。
3. **骑马抽**（左右侧板是五金，木件只剩底板/背板/抽面）。
4. **门 + 抽屉同柜**：抽屉跨整个内宽，且正面开口的缝/覆盖要一起排；今天两者互斥。
5. **门/抽屉与中立板共存**：抽屉按内宽出件，中立板挡在中间；腔级抽屉还没做。
6. **前脸缝**：抽面仍按“格高 − 层缝”出，且底抽与第二抽之间是 2×层缝（首抽不吃缝）。前脸上的上下可见缝要跟正面排版一起做。
7. **抽面与前板之间要不要留调节缝**：现在抽面背面直接贴前板。
