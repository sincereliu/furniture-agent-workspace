# 抽屉滑轨系统规则

回答“抽屉用哪种轨、上下间隙多少、抽芯多深、底板要不要抬起？”；本文件是滑轨系统口径的唯一规则中心。[抽屉尺寸链](drawer-dimension-chain.md) 讲链条顺序，这里讲每个系统的数与查表。

**状态：三节轨与托底轨已落地**（`drawer_runner` + 抽芯档 + 后缝下限 + 轨腔高度 + 格高查表）。独立抽面、骑马抽、按空间装单抽还没做，见文末「未做」。

## 一、一个字段，两套口径

提案只需给 `drawer_runner`（缺省 `side_mount`，等于缺省时不落盘）。其余全部查表：

| 口径 | 三节轨 side_mount | 托底轨 undermount |
| --- | --- | --- |
| 抽芯深度档（不含抽面） | 200 / 250 / 300 / 350 / 400 / 450 / 500 | 240 / 290 / 340 / 390 / 440 / 490 |
| 后缝下限（必须**严格大于**） | 0 | 10 |
| 轨腔高度（底板底面 ↔ 盒体底面） | 0 | 11 |
| 格高 < 该值：空间过低（警告） | 70 | 80 |
| 格高 > 该值：空间过高（警告） | 260 | 不设上限 |

## 二、格高 → 上下间隙

区间**左开右闭**，按顺序匹配；超出最后一档按 20/20 处理（并报警告）。

| 格高 | 三节轨 下/上 | 托底轨 下/上 |
| --- | --- | --- |
| 70 ~ 130 | 10 / 10 | — |
| 130 ~ 220 | 10 / 20 | — |
| 80 ~ 220 | — | 20 / 10 |
| 220 ~ 260 | 20 / 20 | 20 / 20（>220 一律） |
| > 260 | 20 / 20（警告） | 20 / 20 |

## 三、盒高、盒深、后缝

```
格高   = 内部净高 ÷ 抽数
盒高′  = 格高 − 下间隙 − 上间隙
盒高   = 盒高′ 向下取到 10 的整数倍          # 车间要求盒高为 10 的倍数
余量   = 盒高′ − 盒高                        # 0..9，进上间隙
盒体 z = 格起点 + 下间隙
底板 z = 盒体 z + 轨腔高度

可装深度 = 内深 − 抽面厚（内嵌口径，抽面占一块板厚）
盒深     = 抽芯档里 满足「可装深度 − 盒深 > 后缝下限」的最大一档
后缝     = 可装深度 − 盒深                   # 结果，只会 ≥ 下限
```

**后缝是结果，不是输入。** 提案给的 `drawer_back_clearance` 是**最小要求**：准入只校验它大于该系统的下限；实际后缝由档位决定（取档后可能更大）。这样既不会出现“默认 0、抽屉贴柜背”，也不需要提案自己凑档位。

**取整余量进上间隙**：下间隙保持规范值，盒体不往轨上压。

## 四、样例（800×1000×600、板厚 18、3 抽、后缝要求 20）

| | 三节轨 | 托底轨 |
| --- | --- | --- |
| 格高 | 304.667 | 304.667 |
| 下 / 上间隙 | 20 / 24.667 | 20 / 24.667 |
| 盒高 | 260 | 260 |
| 盒深 / 后缝 | 500 / 35 | 490 / 45 |
| 底板 z（相对盒底） | 0 | +11 |

格高 304.667 超过三节轨的 260，所以这一台会带一条 `DRAWER_CELL_TOO_HIGH` 警告（不拦确认）；改成 4 抽就不会。

## 五、警告不拦

`DRAWER_CELL_TOO_LOW` / `DRAWER_CELL_TOO_HIGH` 是**警告**：写进校验报告、显示给人，但不拦确认。真正拦确认的是几何做不出来（盒高取整后 ≤ 0、底板 + 轨腔占满盒高、内深放不下任何一档抽芯）。

## 六、未做

1. **空间不止一种**：现在抽屉只能占满柜内净高（`drawer_count` 均分）。一格 200 装一个抽、层板之间加抽、水平并排两抽，都还表达不了。
2. **独立抽面**（内嵌式抽面，多一块板、可现场调缝）。
3. **骑马抽**（左右侧板是五金，木件只剩底板/背板/抽面）。
4. **背板坐底板**：现在背板通高到盒底（贴底板端面）。改成坐在底板上会多一条 z 轴坐接，制造要同时加一条“坐接不连”的规则，两件事一起做。
5. **前脸缝**：抽面仍按“带高 − 层缝”出，且底抽与第二抽之间是 2×层缝（首抽不吃缝）。前脸上的上下可见缝要跟正面排版一起做。
