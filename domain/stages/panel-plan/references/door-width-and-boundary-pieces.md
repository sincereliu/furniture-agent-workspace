# 门宽、零头与边界件（收口条 / 见光板 / 顶封板）

**状态：口径已定。**

## 一、门宽有两套口径，看"有没有收口条可吸"

**上限：一个柜体最多按 6 扇门处理**（6 × 350 = 2118 ≤ 板长 2440 ✓；7 × 350 = 2450 ✗ 超板长，必须分台或加中立板）。这条上限跟着板幅走：车间用 `1220×2745` 那档时抬到 7 扇（7 × 350 = 2450 ≤ 2745），口径见 [料档与工艺卡](sheet-stock-catalog.md)。

| 情况 | 槽位取整 | 零头去哪 |
| --- | --- | --- |
| **有收口条可吸**（靠墙侧留了收口条） | 截断到 **0.5** | **收口条**（截断 → 单向为正） |
| **没有收口条可吸**（两侧见光、四周不靠墙） | 截断到 **0.1** | **门缝**：有对开门时 —— **对开门组数是偶数 → 各组中缝均分**；组数是奇数 → 全部给**中间**那组的中缝（对称）。没有对开门 → 最靠右的内缝。只有一扇门 → 右边距 |

```
槽位 s   = 柜体宽 / 扇数
槽位取整 s' = 截断到 0.5 或 0.1（看有没有收口条）
成品门宽 w = s' − 2×边距
零头 R   = 柜体宽 − 扇数 × s'
```

**没有收口条时主动询问**：建议按"0.1 + 最靠右那条缝"处理，并说明原因（没有可调件，零头只能进缝）。

**零头归宿（没有收口条时）**——**一个柜体最多按 6 扇门处理**。

### 通用规则：看柜体中心线

```
1 扇门          → 不截断，门宽取精确值（零头最多 1 位小数）
2 扇、5 扇      → 柜体宽是整数时零头恒为 0，天然均分（不用分配）
3、4、6 扇      → 沿柜体中心线看下去：
     中心线落在【缝】上     → 零头全给这条缝
     中心线落在【对开门】里 → 零头全给这组对开门的中缝
     中心线落在【单开门】里 → 就近取它左边的缝（右边等价，0.1 看不出来；代码取左定死）
```

### 回验（全部组合）

| 扇数 | 排布 | 中心线落在 | 零头归宿 | 状态 |
| --- | --- | --- | --- | --- |
| 1 | 单开 | 那扇门 | 无内缝 → 不截断 | ✅ |
| 2 | 全单开 / 1 组对开 | 唯一那条缝 / 中缝 | 那条缝（零头恒 0） | ✅ |
| 3 | 1 组对开 + 1 单开 | 中间那扇门（属于对开） | 该组对开门的中缝 | ✅ |
| 3 | 全单开 | 中间那扇门（单开） | 就近取左缝 | ✅ |
| **4** | **2 组对开** | **两组之间的缝** | **这条缝全吃（0.2）** ← 与"两组均分"不同，见下 | ⚠ |
| 4 | 对开在一侧 + 2 单开 | 对开 ↔ 单开 那条缝 | 这条缝 | ✅ |
| 4 | 对开在中间 + 2 单开 | 对开门的中缝 | 这条缝 | ✅ |
| 4 | 全单开 | 中间那条缝 | 这条缝 | ✅（由通用规则给出） |
| 5 | 任意排布 | —— | 零头恒 0，不用分配 | ✅ |
| 6 | 3 组对开 | 中间那组对开的中缝 | 这条缝 | ✅ |
| 6 | 单+双+双+单 / 单+双+单+双 / 双+双+单+单 / 单+单+双+双 | 第 3 条缝（恰好在中线上：可能是对开中缝、对开↔对开、或对开↔单开） | 这条缝 | ✅（由通用规则给出） |
| 6 | 全单开 | 第 3 条缝 | 这条缝 | ✅（由通用规则给出） |

**为什么这样最省**：偶数扇（4、6）时柜体中心线**一定**落在第 n/2 条缝上；奇数扇（3）时才需要看"中间那扇门属于谁"。所以实现只有几行，且对任何组合都确定。

### 唯一待你择一

**4 扇 2 组对开**：中心线落在两组之间的缝 → 新规则是**那条缝全吃 0.2**；你之前定的是**两组中缝均分（各 0.1）**。按哪个？（其余档两者一致。）

**两档在数学上就没有零头**（柜体宽取整数、槽位截断到 0.1）：

```
2 扇：柜宽/2 的小数只可能是 0 或 0.5 → 都是 0.1 的整数倍 → 零头 = 0
5 扇：柜宽/5 的小数只可能是 0 / .2 / .4 / .6 / .8 → 同理 → 零头 = 0
```

所以"2 扇一档""5 扇一档"只是把规则写全，实际不需要分配动作。

**从已定档归纳（待确认）**：零头只落在**缝**上，且优先落在**对开门的中缝**；只有全单开时才会落到单开门之间的缝。

**除不尽会发生在哪**：零头 R 是 0.1 的整数倍，所以

| 组数（扇数） | 零头可能值 | 均分后 | 结果 |
| --- | --- | --- | --- |
| 2 组（4 扇） | 0、0.2 | 各 0.1 | ✓ 1 位 |
| 2 组（4 扇） | 0.1（需柜宽带 0.05 尾数） | 各 0.05 | ✓ 2 位 |
| 4 组（8 扇） | 0.2 / 0.4 / 0.6 | 各 0.05 / 0.1 / 0.15 | ✓ 2 位 |
| **6 组（12 扇）** | 0.2 | 各 **0.0333** | ✗ **4 位** |
| **8 组（16 扇）** | 1.0 | 各 **0.125** | ✗ 3 位 |

**现实里到不了那一档**：8 扇门在推荐区间（350~450）下要求柜宽 **≥ 2824 mm**，超过板长 2440 → 必须分台；所以可达的扇数 ≤ 6、组数 ≤ 3，**均分永远不会超过 2 位小数**。真遇到超宽特例时，按"**组数 ≥ 4 不分，零头全给中间那组**"处理。

| 3604 / 9 | 400.444 | 397 | **+4.0** |

**没有收口条（截断到 0.1）**：

| 柜体宽 / 扇数 | 槽位 | 成品门宽 | 零头 | 归宿 |
| --- | --- | --- | --- | --- |
| 1000 / 3（1 单开 + 1 组对开） | 333.333 → **333.3** | 330.3 | **+0.1** | 对开门中缝 3.0 → **3.1** |

| --- | --- | --- | --- | --- | --- |

### 门宽推荐区间（车间数据，已给）

| 项 | 字段 | 值 | 档 |
| --- | --- | --- | --- |
| 门宽下限 | `min_door_width_mm` | **350** | `typical`（推荐值） |
| 门宽上限 | `max_door_width_mm` | **450** | `typical`（推荐值） |

**含首尾**：350 和 450 本身都算在推荐区间里。

**判定行为**（评估器的 `_apply_door_width_range`）：

| 情况 | 结果 |
| --- | --- |
| 门宽 < 下限 | finding `door_width_narrow` |
| 门宽 > 上限 | finding `door_width_wide` |
| 档是 `typical`（当前） | **`assumption`——只提示，不拦** |
| 档改成 `confirmed`（车间确认后） | **`blocked`——拦下** |
| 只给一头 | 允许（只给上限或只给下限都行） |
| **一头都不给** | **不判**，也不报 `unjudged`（门是必填项，每次调用都报会变成噪音） |

**提示时要一起给的出路**：

| 症状 | 出路 |
| --- | --- |
| 门太窄 | **减扇数**（例：1502 宽 5 扇 = 297 → 改 4 扇 = 372 ✓） |
| 门太宽 | **加扇数**（例：1500 宽 2 扇 = 747 → 改 4 扇 = 372 ✓） |
| **换扇数也无解** | 改柜宽、加中立板分格、或把这一段改成抽屉/开放格 —— 例：**1000 宽**做门时 2 扇 = 497（太宽）、3 扇 = 330（太窄），**没有合法扇数** |

（可解区间：1 扇 353~453、2 扇 706~906、3 扇 1059~1359、4 扇 1412~1812、5 扇 1765~2265、6 扇 2118~2718。）

## 二、w < 18：主动建议加宽柜体

余量比单板收口条（18）还窄时，**不是收口条的问题**：

> **主动建议加宽柜体**——让柜体吃掉这一段，余量归零，不留收口。

## 三、收口条分档

| 宽度 w | 是什么 | 状态 |
| --- | --- | --- |
| **18 ≤ w ≤ 20** | 单板收口条（18 板，20 = 含零头上限） | ✓ 可做 → **提议** |
| **20 < w ≤ 30** | **没有可用的做法** | ✗ **`blocked` + 给原因 + 三条出路** |
| **30 < w < 50** | 非标规格 | ⚠ **需客户明确指出**（`assumption`） |
| **w ≥ 50** | L 型收口条（50 标称，可到 53 吸零头） | ✓ 可做 → **提议** |

### 死区（20 < w ≤ 30）的话术

原因：单板最宽到 20，再宽就得做 L 型，而 L 型最小 50——这一段两头不靠。同时给三条出路：

```
① 让柜体变宽吃掉这一段（柜体直接贴墙，不留收口）
② 把余量挪到另一侧分摊，让两侧各自落进 18~20 或 ≥50
③ 改模数组合（加减一台柜或改门数），把这一侧推到 0、或推到 ≥50
```

### 零头把"可做"推进死区的兜底

截断的零头**只增不减**，会出现本来能做、被零头搞死的情况：

```
某侧余量 19（单板档） + 零头 2.0 = 21 → 掉进死区 ✗
```

兜底三条（按顺序用）：

1. **零头挪到另一侧**（或两侧分摊）；
2. **该侧柜体宽 +1 ~ 2 mm**（门宽少 0.5、柜宽多 0.5 —— 门宽取整与柜宽取整**解耦**）；
3. **柜体直接贴墙**（余量归零，不留收口）。

## 四、什么时候问（触发）

| 位置 | 问什么 | 选项 |
| --- | --- | --- |
| **靠墙侧** | 要不要收口条 | 单板 18~20 / L 型 ≥50 / 不留（贴墙） |
| **见光侧** | 要不要见光板 | 要 / **不要**（有时并不需要） |
| **顶部** | 要不要顶封板 | 要 / 不要 |

**一件一问，带选项与原因**；客户的选择进台账。不要默认加，也不要默认不加。

## 五、物化（板件阶段内部）

| 类型 | 板件 |
| --- | --- |
| **单板收口条** | **一块板**：X = 收口宽、Y = 18（板厚）、Z = 柜高 |
| **L 型收口条** | **两块板**（前面板 + 回转板），按装配出；BOM、封边、连接、孔各多一份 |

**位置**：收口条是**包络内部的切分**（包络 = 占用段：柜体 + 收口）。包络若只算柜体本身，则收口是额外占用，**必须布局先给段**。
