# 沿墙铺满

客户指定一面墙，这段空墙铺满柜子。台数由墙长决定：放得进一台就是一台，放不下就两台、三台，多少台都行。

## 输入

在那面墙的一件家具上写 `placement.fill: true`，并写 `kind`（柜类，取工艺目录 `families`）。宽度可省。没写 `kind` 就停问，代码不猜柜类。

房间上没有 `spaces` 字段。旧工程如果还带着 `spaces`，读入时会被拒绝，删掉这个键再打开。

## 怎么拆

1. 这段空墙的长度由摆放算出来：扣除与这件高度相交的门窗、贴墙障碍、已经摆上的家具。没给 `offset_mm` 时取最长空段；给了就从该偏移铺到该空段的终点。
2. 一台的宽度上限是该柜类门宽上限的两倍。数字在工艺目录，代码不写死。
3. 空墙不超过上限，就是一台，id 为 `{原id}_u1`，宽度就是这段空墙。
4. 超过上限，台数是墙长除以上限后向上取整。墙长是整数毫米时，前面几台一样宽，多出来的毫米加在远端那几台，每台仍不超过上限。宽度加起来等于这段空墙。
5. 沿墙接开：第一台的偏移是这段空墙的起点，下一台的偏移等于上一台的偏移加上一台上的宽度。相邻两台边对边相接。

展开后的单元是普通靠墙件，不再带 `fill`。它们继承原件的柜类、进深、高度、离地高度，以及 `manufacture: false`。单元上不写 `kind`。一台时标签用原标签；多台时标签是「原标签 1」「原标签 2」。

没有铺满的房间不读工艺目录。

## 不算进去的

收口条、踢脚、台面高、单元宽档、功能格、开门方式都留在工艺目录里。铺墙时不拿来扣宽度，也不据此停问。
