# 柜内结构 → 板件：单一来源与物化清单（设计决定）

回答"评估出来的毫米怎么变成板件"。前置：[柜内结构契约](interior-structure-contract.md)（人只说三件事，尺寸由程序算）。本文只定接口与分期，**不含 A/B 凑整口径**（那是车间决定，见文末）。

## 决定 1：单一来源——谁拥有哪些数

| 数 | 谁拥有 | 谁消费 |
| --- | --- | --- |
| **门**：每扇宽、每扇起点、逐条缝宽、缝中心、左右边距、`pairs` | **评估器**（`evaluate_interior`） | 板件（出件）、审查清单、中立板锚定 |
| **中立板**：区间（由缝 + `seam_align` + 板厚算） | **评估器** | 板件（出一块竖板）、各腔边界 |
| **分段**：各段长度（由断口 + 板厚算） | **评估器** | 板件（分段成件） |
| **各腔净空**：宽/高/深 | **评估器** | 判定（内容放不放得下）、审查清单 |
| **内容**：层板 / 抽屉 / 挂衣 / 空 | **提案**（腔级，阶段 2 落地） | 板件 |
| **包络**：id / 落地还是吊柜 / 宽 / 深 / 高 | **布局**（不动） | 评估器与板件 |
| **深度方向**的 `front_gap`、料厚、踢脚高、抽屉尺寸链 | **已准入的提案/料档** | 板件（沿用现状） |

**规则**：板件阶段**不再自己算门宽与缝**（今天 `topology_solver._door_panels` 自己算一套，与评估器形成两套公式）。有 `interior` 时**以评估器输出为准**；没有 `interior` 时走老路径。

**校验分工**：

| 判什么 | 谁判 |
| --- | --- |
| 合不合理（锚、缝、净空够不够、段太短、凑整） | 评估器（`findings`：`blocked` / `assumption` / `unjudged` + 两侧代价） |
| 几何自洽（板件不重叠、依赖闭环、拼得出来） | 板件阶段（沿用现有校验） |
| 能不能做出来（料、孔、五金、加工） | 制造及以后（不动） |

## 决定 2：物化清单与分期

| 批次 | 物化什么 | 依赖 | 验收 |
| --- | --- | --- | --- |
| **0** | **先确认回归基线**（`test_panel_output_baseline.py`）：老输入产出已冻结，动板件前跑一次 | 无 | 基线绿；红了先判意外还是故意 |
| **1** | **中立板**（一块竖板：尺寸/位置/依赖）+ **分段板**（顶板/底板/踢脚/背板 → 多段各自成件） | 评估器输出区间与段长 | 契约第 1 节的四种分段组合都能出件；老输入逐字节不变 |
| **2** | **多门**（>2 扇，按扇序出件；铰链信息交制造） | 撤掉"`n_doors` 大于 2"的停问；板件按评估器的扇序出件 | 2400/7、1211/4、1511/6 能出件；对开分组传到制造 |
| **3** | **按腔内容**（每腔自己的层板/抽屉/挂衣） | 内容从柜级升到腔级（与组件化合并） | 混合分区（左挂衣右抽屉）能出件 |

**板件 id 规则**（分段与多扇要能区分）：

```
中立板      {cabinet_id}__divider_{n}
分段板      {cabinet_id}__{role}_{n}        # top_panel_1 / toe_kick_2
门          {cabinet_id}__door_{n}          # 沿用现有序号思路
```

## 决定 3：不变量（改这个不许破）

1. **产物契约不变**：板件 id / 角色 / 尺寸 / 位置 / 依赖 / 接触（大面–端面）形状不动 → 制造、特征树、CAD、交付**无感**；
2. **布局不动**：包络仍是五个字段；
3. **老输入逐字节不变**：没有 `interior` 的工程走老路径，产出与今天完全一致（回归条件）；
4. **缺数据停问**：净空/段宽判定没有 `confirmed` 数据时，给 `assumption`/`unjudged`，不拿典型值冒充；
5. **继承判据不动**：仍按包络五个字段判"内容变没变"；板件内部结构变了会体现为该台重算，这是应然。

## 决定 4：A/B 中立（凑整口径明天定）

- 把凑整差异**关在评估器的一个函数里**（`_layout_doors`），外部看不见；
- 物化只消费输出（每扇宽 / 起点 / 缝 / 中心 / 左右边距 / 区间 / 段长）——**接口在 A、B 下相同，只有数值不同**；
- 契约文字写成两头都成立："**缝基值 = 2×边距；某条缝可因吸收凑整差而偏离基值**"；
- 测试分两组：**结构类**（区间/净空/分段，A/B 通用）+ **凑整类**（A 或 B 各一组）→ 明天定了只换第二组。
