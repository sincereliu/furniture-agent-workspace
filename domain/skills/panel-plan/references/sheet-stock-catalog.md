# 料档与工艺卡

回答“板件厚度和板幅从哪来，提案要不要写，运行时如何准入？”；本文件是料厚目录、板幅、工艺卡和角色绑定的唯一规则中心。

## 车间进料

只有两种板：

- **柜体板**：目录 `{18, 22}` mm。工艺卡默认 `18`。
- **9 厘背板**：常量 `9` mm。

门板不是第三种板，只用柜体板。多数跟柜体板；用户明示时门可单独为 `18` 或 `22`。

## 板幅

车间进料就两档，都是 1220 宽：

| 板幅 | 什么时候用 |
| --- | --- |
| `1220×2440` | 工艺卡默认档 |
| `1220×2745` | 客户要长板时：柜高或顶底板长度超过 2440，只有这一档切得出来 |

- 字段 `sheet_width_mm` / `sheet_length_mm`，**两个一起给或者都不给**；只给一个是没说清哪一档，准入直接拒。
- 都不给 → 按工艺卡展开成 `1220×2440`，写进已准入 spec 的具体毫米。
- 给定值必须正好是上面两档之一，否则拒。
- 它不是"每块板各自的开料尺寸"，是车间买什么板。板件、BOM、CAD 与校验读的都是同一份。

**校验**：板厚取三边里最小的那条，另外两边是平面尺寸；要求
`min(平面两边) ≤ sheet_width_mm` 且 `max(平面两边) ≤ sheet_length_mm`，否则报
`PANEL_EXCEEDS_SHEET`（error，拦确认）。旋转 90° 不改变结果，所以顺纹方向和它无关——
改顺纹救不了超尺。

出路三条：加中立板把背板切开、改柜宽/柜高、分体或拼板。`cover` 背板不按腔打断，
宽柜盖不住时只能改 `groove`/`insert`。

## 角色绑定

| 零件 | 料档 |
| --- | --- |
| 侧板、顶底板、层板、踢脚板、踢脚支撑、背拉条 | 柜体板 `board_thickness` |
| 抽屉前板、抽屉侧板、抽屉后板、抽屉底板 | 柜体板 `board_thickness` |
| 后背板（`groove` 入槽 / `cover` 外盖） | 9 厘背板 `back_thickness = 9` |
| 后背板（`insert` 内嵌） | 柜体板 `board_thickness`（内嵌背板是柜体围合件，不能用 9 厘背板） |
| 门板 | 柜体板 `door_thickness`，省略则等于 `board_thickness` |

当前拓扑没有独立的抽屉面板。若以后增加，按门板料走，不按抽屉盒另开一档。

`board_thickness` 的规范语义是柜体板厚，不是「每块板各自的厚度」。踢脚条高是 `toe_kick_height`，背拉条高是 `back_rail_height`，厚度都走柜体板。

## 提案

- `board_thickness`、`back_thickness`、`door_thickness`、`drawer_bottom_thickness`、`drawer_back_thickness` 可省略；`sheet_width_mm` / `sheet_length_mm` 两个一起省略。
- 省略由本工艺卡展开后再写入已准入 spec；冻结 JSON 与下游仍带具体毫米，不得缺字段。
- 写出的值必须落在目录内。`groove` 入槽 / `cover` 外盖背板写出时必须是 `9`；`insert` 内嵌背板写出时必须等于柜体板厚。抽屉底/背写出时必须等于已准入柜体板厚。板幅写出时必须正好是两档之一。
- 裸 CLI/API 没有 LLM 时同样允许省略料档；这是结构化协议，不是按柜型猜方案，也不是自然语言默认值。
- 「厚一点」「用长板」等开放说法归 LLM，改写成目录成员后再写入；代码不解释这些话。

## 工艺卡展开

1. 未给 `board_thickness` → `18`；给了则必须是 `18` 或 `22`。
2. 未给 `back_thickness`：`groove` 入槽 / `cover` 外盖 → `9`，`insert` 内嵌 → 已准入柜体板厚。给了则必须等于该模式对应料档。
3. 未给 `door_thickness` → 等于已准入柜体板厚；给了则必须是 `18` 或 `22`。
4. 未给 `drawer_bottom_thickness` / `drawer_back_thickness` → 等于已准入柜体板厚；给了则必须等于柜体板厚。
5. 未给 `sheet_width_mm` / `sheet_length_mm` → `1220 × 2440`；只给其中一个直接拒。

用户没提板厚时，展示一行「料档按工艺卡：柜体板 18 / 9 厘背板 9 / 门同柜体板」，不把五条厚度列入假设清单。只有覆盖了目录值时才展示改过的那一档。板幅默认不展示；改成 `1220×2745` 时说明一句「按长板下料」。
