# 预览页的访问模式与外网分享（设计稿）

给助手、评审和将来的自己看：这一页说清**谁可以写**、`?mode=view` 到底是什么、
以及"给不在本机的人看"那条路按什么形状铺。契约细节见 [运行时契约](runtime-contract.md)「写权限」段；
未落地部分登记在 [编排与生命周期未落地需求](backlog.md)。

## 已经落地的两件事

**一、写权限只有一道门（服务端）。**

判据 `server.access_scope(request)` 只看 `request.client.host`：本机（`127.0.0.1` / `::1`）为
`local`，其余为 `denied`；`may_edit(request)` 就是 `scope == "local"`。
四个**有副作用**的端点共用它，且都在动手之前拒（不留半成品）：

| 端点 | 副作用 |
| --- | --- |
| `POST /api/preview/shutdown` | 停掉本机预览进程 |
| `POST /api/room-scene/save` | 写场景源文件 |
| `POST /api/room-scene/{scene_id}/edit` | 重算并落盘场景源 |
| `POST /api/plan-room/cad` | 写 CAD 源文件与 STEP |

读端点不设限——服务本来只监听 `127.0.0.1`，外面进不来。测试盯着两件事：非本机来源一律 403
且没落任何文件；**判据只有一处**（主机名白名单全文只出现一次，端点里不再出现 `request.client.host`）。

**二、`?mode=view` 是表达，不是权限。**

预览页带 `?mode=view` 时出**分享形态**：身份牌换成「只读分享 · 链接可转发」（琥珀色）、
提示语换成"只看不改，位置由房主那边更新"、**页面里根本没有「退出」按钮**（不生成，而不是生成后藏起来——
那按钮能停掉本机的预览服务，不该给拿到链接的人）。写链接用 `project_preview.preview_url(id, mode="view")`
或 `open_project_preview(id, share=True)`。

它**不承担任何权限**：地址栏谁都能改，参数一删就回到普通形态。测试盯的就是这一点——判据函数
`access_scope(request)` / `may_edit(request)` 连 `mode` 都拿不到，所以它不可能参与授权。

## 外网分享：按 token 形态铺（尚未实现）

**为什么不是 `?mode=view` 就够**：给外人看时，对手恰恰是"拿到链接的人"，而他能改地址栏。
表达层拦不住他，只有服务端凭证能。所以外网那条路必须是 token。

**形状**（复用已经落好的门，不动任何端点）：

1. `access_scope()` 多认一种凭证来源 `shared`：请求带着有效分享凭证 → `shared`；`may_edit("shared")` 恒假。
   写端点的 `if not may_edit(request)` 一行都不用改。
2. 路由：`GET /share/<token>` → 校验凭证 → 返回分享形态的预览页（等价于今天的 `?mode=view`）。
3. 凭证存哪：跟项目放一起（`store/<project-id>/shares/<token>.json`），内容至少含
   `project_id` / 创建时间 / 过期时间 / 撤销位。**不放进项目数据之外的地方**，省得两处状态。
4. 生命周期：可撤销、可过期（建议默认 7 天，可续）；只读，永远改不了任何东西。
5. 通道（真正的门槛，不在代码里）：今天服务 `host="127.0.0.1"`，外面进不来。要分享必须先有通道——
   隧道（cloudflared / ngrok 之类）、监听 `0.0.0.0` + 端口转发、或部署到服务器。
   **开门之前先确认门在位**：任何一次"先开个隧道试试"都会把所有写端点暴露出去，除非 `access_scope`
   已经按上面第 1 条认凭证。这条顺序是硬要求，不是建议。
6. 页面变体：外网那版不该出现「退出」（能停你的服务）、不该出现草稿页入口、不该显示本机绝对路径。

**明确不做**：外人在页面上**改**。那要并发、冲突合并、审计与 `expected_version` 一整套，
属于"页面写项目"那条线（P3 之后），与分享通道无关。

**代价评估**：通道与安全是主要成本，代码侧很小——判据多一个分支、一个路由、一份凭证存储，
前提是别把 `request.client.host` 比较散到各个端点里（那正是今天这道门要防的债）。
