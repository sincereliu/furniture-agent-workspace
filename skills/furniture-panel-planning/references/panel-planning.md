# 板件规划

回答“有哪些实体家具部件？”；位于布局后、制造/特征树前。板件是制造零件，不是 CAD 实体。

## 记录

常见角色：左右侧板、顶/底/背板、层/隔板、门/抽屉面、横撑和踢脚板。每块记录稳定标识、角色、成品尺寸/厚度、材料、数量、朝向、位置和制造注释。

## 板件规则

- 用角色及其与成品包络/区域的关系表达板件；位置用最小角点、包络、面或板件关系。
- 层板和隔板不得与选定的背板结构冲突。
- 门板和抽屉面板必须关联其开启策略及净空包络。
- BOM 和五金记录应与 CAD 实体分离。
- 背板：`groove` 尺寸为净宽/高各加 `2×groove_depth`，且仅此模式生成 `back_rail`；`insert` 为内部净宽×净高，位于 `back_offset`；`cover` 为成品宽×高，位于 `Y=0`，柜体从其前侧开始。
- 入槽背拉条夹在左右侧板之间，数量按 `floor(internal_height / 500)` 计算，并使用 `back_rail_height` 等距布置。
- 本阶段只定背板/背拉条尺寸、位置、依赖；槽、封边、连接和孔位归制造阶段。
- 踢脚区域由布局阶段提供；本阶段生成前后踢脚板和支撑板。自动支撑数量采用项目默认策略：`W < 600 → 0`，否则 `1 + floor((W-600)/300)`；用户给出的显式数量优先且必须保留正间距。

## 边界

- 不定义制造规则、封边/钻孔/五金、特征树/CAD/STEP、JSON、命令或工厂批准状态。
- 材料/公差/连接/封边/五金交给制造；建模依赖和 CAD 表达交给特征树。
