# 柜体结构类型说明

---

## 一、落地柜 (FloorCabinet)

### 结构示意

```
┌─────────────────────┐
│       顶板           │  ← 嵌在左右侧板之间
├────┬────────────┬────┤
│    │            │    │
│ 左 │   层板×N   │ 右 │  ← 等分内部净高
│ 侧 │  (固定)    │ 侧 │
│ 板 │            │ 板 │
│    ├────────────┤    │
│    │   底板     │    │  ← 嵌在侧板之间，踢脚线上方
│    ├────────────┤    │
│    │  踢脚框架  │    │  ← 高50mm
│    └────────────┘    │
│                      │
│  ← 背板（距后18mm） →│
└──────────────────────┘
        ↑ 门板 ×2 ↑
```

### 尺寸关系

| 变量 | 来源 | 说明 |
|------|------|------|
| W | 用户输入 | 柜体总宽 |
| H | 用户输入 | 柜体总高 |
| D_total | 用户输入 | 柜体总深 |
| T | 板厚 (18mm) | 侧板/顶底板/层板厚度 |
| T_back | 背板厚 (9mm) | 背板厚度 |
| T_door | 门板厚 (18mm) | 门板厚度 |
| side_depth | D_total - T_door - 2 | 侧板深度（减门板和铰链间隙） |
| internal_W | W - 2T | 内部净宽 |
| internal_H | H - 50 - 2T | 内部净高（减去踢脚线和上下板厚） |

## 二、吊柜 (WallCabinet)

### 与落地柜的区别

| 特征 | 落地柜 | 吊柜 |
|------|--------|------|
| 踢脚线 | 有 (50mm) | 无 |
| 侧板 | 从 z=0 到 z=H | 从 z=0 到 z=H（通高） |
| 底板 Z | z = toe_kick_h (50mm) | z = 0 |
| 内部净高 | H - 50 - 2T | H - 2T |
| 门板高 | H - 50 - 2×margin | H - 2×margin |

## 三、衣柜 (Wardrobe)

### 特殊结构

```
┌─────────────────────┐
│       顶板           │
├────┬────────────┬────┤
│    │ 顶部层板×N │    │  ← 等分挂衣区上方空间
│    ├────────────┤    │
│ 左 │            │ 右 │
│ 侧 │  挂衣区    │ 侧 │  ← 高 1000mm，空旷
│ 板 │  (挂衣杆)  │ 板 │
│    ├────────────┤    │
│    │ 叠放层板×4 │    │  ← 固定，紧密排列
│    ├────────────┤    │
│    │   底板     │    │
│    ├────────────┤    │
│    │  踢脚框架  │    │
└──────────────────────┘
        ↑ 门板 ×2 ↑
```

### 挂衣杆参数

- 挂衣杆高度: 默认 1000mm（从内部底面算起）
- 挂衣杆位置: 挂衣区顶面下方 50mm
- 挂衣杆类型: 铝合金挂衣杆（BOM 标出，不生成 3D 模型）

## 四、中立板分区（所有品类通用）

当柜体较宽（>1200mm）或有分区需求时，通过 `add_divider(x_center)` 添加中立板：

```
┌─────────┬─────────┐
│  左区   │  右区   │  ← 中立板在中轴线
│         │         │
│ 层板 L  │ 层板 R  │  ← 被中立板打断，宽度各自计算
└─────────┴─────────┘
```

使用 `gen.add_shelf(z, x_range=(x0, x1))` 限制层板宽度，配合中立板分区。

## 五、层板类型

| 类型 | panel_type | 连接件 | 封边 |
|------|-----------|--------|------|
| 固定层板 | fixed_shelf | 三合一连接件 | 前边 ABS 1.0mm |
| 活动层板 | movable_shelf | 层板托 (二合一) | 前边 ABS 1.0mm |
| 中立板 | divider | 三合一连接件 | 前边 ABS 1.0mm |

固定层板和活动层板的区别：
- 固定层板：深度 = side_depth - back_offset - T_back（不穿透背板）
- 活动层板：深度同上，但连接件不同（可调节高度）
