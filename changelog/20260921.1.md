# 20260921.1 — 测试入口与跨阶段定位表

新增 `domain/skills/cad-generated/scripts/run_tests.py` 作为唯一测试入口：调已有的 `runtime_paths.bootstrap_runtime_paths()` 装好各阶段包，再 discover `tests/` 下的全部测试，用标准库 `unittest`，零新依赖；`-p` 跑单个文件，`-v` 列出未失败用例，并单独报告 unexpected pass。配套在 [开发环境](../.agents/skills/furniture-agent/references/dev-environment.md) 加「跑测试」一节（含受限沙箱下临时目录被拒的已知限制）。同时修正文档漂移：README 的 `POST /api/plan-layout` 改为实际的 `/api/plan-room` 系列并修正架构图里过期的阶段名；运行时契约补全 9 个 API 端点（原漏 5 个场景状态端点）并去掉与表格重复的旧段落；删除过期的 `temp/architecture-map/`，把跨阶段字段定位表收进[运行时映射](../domain/skills/manufacture-plan/references/runtime-map.md)。`length_mm`/`width_mm` 轴映射缺陷登记进 [backlog](../domain/skills/manufacture-plan/references/backlog.md) 并挂自动提醒测试。

### 边界

- 新增 `run_tests.py` 只做路径装配与 discover（`structured_protocol`），不含领域默认值、分支映射或自然语言解析；运行时逻辑一行未改。
- 新增测试均为守卫与提醒：入口可发现性、契约端点与 `server.app.openapi()` 对账、定位表路径存在性。路径对账测试首次运行即抓出 `hardware_rules.yaml` 的错误位置与契约漏记的 `/health`、`/`。
- `length_mm`/`width_mm` 缺口用 `@unittest.expectedFailure` 标记：缺口关闭时转为 unexpected pass、套件转红，提示更新 backlog 条目。未引入运行时行为变更。
