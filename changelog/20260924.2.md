# 20260924.2 — 页面身份牌 + 房间药丸切换 + `?room=` 深链

两页（项目只读预览 / 草稿编辑器）外观几乎一样，看不出这一页能不能改；多间房只能在下拉里切，切完地址栏没变化，"把次卧那一间发给别人看"表达不出来。

### 身份牌

- 页眉标题下加 `#mode-badge`：预览页「只读预览 · 由对话更新」（蓝）、草稿页「草稿 · 不影响项目」（灰）、分享形态「只读分享 · 链接可转发」（琥珀，见 20260924.3）。
- 模板占位 `__MODE_BADGE__` 由 `render_project_preview()` / `render_editor()` 各自填；`render_project_preview()` 增加 `mode` 参数。

### 房间切换

- `#room-switch` 下拉改成页眉一排药丸按钮 `#room-band`（`aria-pressed` 标当前），**只有一间房时整条藏掉**，不留点了没反应的控件。
- `syncRoomSwitch()` → `syncRoomBand()`：房间列表签名没变时只改 `aria-pressed`，不重建 DOM。

### 深链与地址栏

- `?room=<id>`（写成 `#room=<id>` 也认）直接打开某间房；三者可叠加，顺序 = 房间 → 视角 → 选中件。
- 切房间时 `history.replaceState` 同步地址栏的 `?room=`，其余参数（`mode` / `view` / `item`）原样保留，链接可分享、可复现。
- 注意：只改 `#` 后面的部分浏览器不重载页面，深链不会重新生效——要发深链就用整条新地址（已写进契约）。

### 文档

- 契约增加房间导航、身份牌、深链顺序；`layout-plan/references/runtime-map.md` 与两份 backlog 同步。

### 验证

- 293 项测试通过（含只读/可编辑两支、占位符清空、身份牌文案）。
- 无头 Chromium 实测：两粒药丸且 `aria-pressed` 跟随；地址栏 `?room=bedroom` → 点击次卧后 `?room=second-bedroom`；`?room=second-bedroom` 直达；`?room=…#view=top&item=wardrobe` 三件事同时生效；无 JS 报错。
