# 20260924.7 — 编辑租约：同一时刻只有一个写者，人永远抢得回来

页面（拖动）和助手（对话）都能改同一个项目的布局。两边同时改就互相覆盖，而 `expected_version` 只能**事后**发现（409），不能事前避免。这一批在写路径上加了一道**编辑租约**。

### 租约落盘，因为写者不在同一个进程里

- 落在 `store/<project-id>/edit-lease.json`（tmp + replace 原子写）。页面走 HTTP 服务进程、助手直接调 orchestrator 跑在另一个进程，内存里的锁互相看不见，所以它是**磁盘上的状态**。
- `LEASE_TTL_SECONDS=45`：没续租就失效（页面每 5 秒心跳，助手每步续一次）。关标签页、崩溃、断网、断电都不用管。

### 三条规矩

1. **不静默接管**：被别人持有就是 `LeaseHeld`，接口回 **423**（带 `holder` / `label` / `expires_in`）。
2. **人把活交给助手 = 授权让出**（方案 B，不再多问一句）：`handover_to_agent()` 显式转移；工具面在**写动作之前**自动做这件事，并在结果里回 `handover`（`taken_over` + 一句 `message`），由模型转告人"页面已切成只读，我做完还给你"。只读类调用（如 `furniture_get_project`）不接管。
3. **人永远抢得回来**：`transfer()` 是原子的，页面的「收回编辑权」按钮走 `/edit-lease/takeover`；收回后助手下一次写会拿到 423 并停下。租约不是用来把主人关在门外的。

### 接口与状态码

- `POST /api/project/{id}/edit-lease`（申请 / 续租）、`DELETE`（归还，页面卸载时 keepalive 发）、`POST …/edit-lease/takeover`（强制收回）。三个都在 `may_edit` 门后（本机）。
- 写请求带 `X-Edit-Lease: <token>`；租约空闲或持在调用方手里才放行。**状态码分工**：403 不许写 · 409 信息过期 · 422 改动不合法 · **423 编辑权在别人手里**。
- 检查点在**写路径门面**（`project_layout_edit.edit_project_layout`），不在 HTTP 中间件——否则锁不住助手（它不走 HTTP）。

### 看得见

- 布局文档与工具面快照都带 `lease` 快照（`holder` / `label` / `expires_in`，**不含 token**）。页面每秒轮询的正是这个文档，所以"助手正在处理"不需要多发一个请求；租约变化与版本无关，`pollLayout` 在比对版本**之前**先应用它。
- `id` 公开（页面据此分辨"那个 page 就是我"还是"另一个窗口"），`token` 是秘密（`sessionStorage` 存、写请求带回）。
- 预览页现在显示：没有租约时不显示牌子；助手持有时「助手正在处理 · N 秒后自动释放」+「收回编辑权」按钮；自己持有时「编辑权在你手上」（绿色）。分享形态不给外人这个按钮。
- 页面这一侧（本批范围）只做"看得见"与"抢回来"：预览页今天仍是只读，所以它**不申请**租约；自己申请、心跳、闲置让出是页面接入那一步的事。

### 验证

- 364 项测试通过（新增 23 条）：申请 / 续租 / 第二个窗口被拒 / TTL 过期后可被接管 / 释放 / 外来 token 释放被拒 / 强制收回 / `check_write` 只放行持有者 / 接管只在"从页面手里"时为真 / 四个 HTTP 状态码 / 租约端点仅本机 / 项目不存在 404 / 页面无 token 写被 423 / 助手直接调门面也被挡 / 收回后页面能写 / 文档与快照带租约且不含 token / 工具面自动接管并报 `handover` / 只读调用不接管 / 落盘形状。
- 真服务 + 无头 Chromium 实测 10/10：无租约时牌子隐藏；从页面手里接管后页面显示「助手正在处理」（按钮出现）；点「收回编辑权」→ 租约归页面、按钮消失、牌子变「编辑权在你手上」；文档带快照且不含 token；无 JS 报错；**离开页面即归还**。
  - 记录一个实测细节：Playwright 的 `page.close()` 直接杀渲染进程、不触发卸载事件，所以"归还"要用**导航离开**来验（与真实关标签页同一条 `pagehide` 路径）。即便 `pagehide` 没跑到（断电、杀进程），45 秒 TTL 也会兜住。
