# 20260910.1 — panel-plan 连接开关落地、几何单源、Skill 操作面

把上次 panel-plan 审计里的五条建议收进同一轮：连接默认可执行、公式不再双写、Skill 补操作面、术语/死代码清理、YAML 能力写实。

### 连接层

- `PanelJoint.connection` 为已解析的 `on/off`；`compute_joints()` 之后按默认表写入。旧 payload 缺字段按 `on` 加载。
- 默认 `off`：跨装配、背板↔固定层板、背拉条↔背板；其余结构接触 `on`。
- 制造 `TrinityConnector` 先过滤 `connection==off`，轴/`cam_face` 只用于选三合一五金。
- 本轮没有逐条覆盖提案字段；`connection-contact-defaults.md` 标明已落地与未做。

### 几何单源

- 新增 `construction_geometry.py`：抽屉尺寸链、层板定位、踢脚支撑、背拉条位置只在此处计算。
- 求解器物化 `PanelPlacement`，校验比对同一组数字。

### Skill / 术语

- `SKILL.md` 补用户原话触发、假设展示和必须消歧的停点；拓扑 YAML 写明只是柜型骨架。
- `CabinetStructure.n_doors` 取代结构输出里的 `door_count`，加载时有界迁移。
- 层板不再接受 `type` 别名。删除无引用的 `panel_face.py` 与一行转发的 `cabinet_panel_planner.py`。
- `design-intent` 把门/层板/抽屉改指板件阶段；房间摆放仍是独立 `layout-plan`。

### 边界

- 新增代码理由：`schema`（connection / n_doors）、`calculation`（默认表与几何）、`state`（结构字段迁移）、`validation`（制造消费开关）。无自然语言映射，无柜型 profile。
