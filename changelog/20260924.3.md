# 20260924.3 — 写权限收成一道服务端门 + 只读分享形态

有副作用的端点此前没有任何门：停进程、保存场景、编辑场景、出房间 CAD 只要连上端口就能调（今天靠"服务只监听 127.0.0.1"兜着，一旦为了分享放开监听就等于全部公开）。同时"只读"若靠 URL 参数表达，谁都能改地址栏——**URL 参数不是权限**。

### 写权限门

- 新增 `server.access_scope(request)`：唯一判据，只看 `request.client.host`（本机 `127.0.0.1` / `::1` 为 `local`，其余 `denied`）；`may_edit(request)` = `scope == "local"`。
- 四个有副作用的端点共用它并**在动手之前**拒（不写一半再报错）：`POST /api/preview/shutdown`、`POST /api/room-scene/save`、`POST /api/room-scene/{id}/edit`、`POST /api/plan-room/cad`。读端点不受限。
- 将来外网只读分享在这一处多认一种凭证（`shared`），各端点不用动。

### 只读分享形态

- 预览页带 `?mode=view` 时：身份牌换「只读分享 · 链接可转发」、提示语改成"只看不改，位置由房主那边更新"、**不生成**「退出」按钮——那按钮能停掉本机的预览服务，不该给拿到链接的人。
- 写链接用 `project_preview.preview_url(id, mode="view")` 或 `open_project_preview(id, share=True)`；日常给出的链接不变。
- `?mode=view` 与 `?room=` 叠加正常，切房间时 `mode` 不会被冲掉。

### 边界

- `?mode=view` **只是表达，不承担权限**：判据函数连 `mode` 都拿不到（测试钉住）。
- 外网分享的 token 形态（`GET /share/<token>`、凭证落 `store/<id>/shares/`、可撤销可过期）与"开通道前先确认门在位"的顺序，记在设计稿 `references/preview-access-design.md`，**尚未实现**。

### 验证

- 写权限门后 297 项、分享形态后 299 项测试通过。
- 新增测试替身 `tests/fake_request_support.py`（本机 / 非本机两种来源）与四条行为断言：远程拒停进程、远程保存不落一个文件、远程编辑文件不变、远程出 CAD 连生成都不触发。
- 一条形状测试盯"判据只有一处"：主机名白名单全文只出现一次，端点里不再出现 `request.client.host`。
- 无头 Chromium 三态实测：普通 `readonly` + 1 个退出按钮；`?mode=view` → `readonly share` + **0** 个退出按钮；`?mode=view&room=second-bedroom` → 直达次卧且 `mode` 保留。
