## 待修：圆角桌面接触检测假定存在索引

涉及文件（相对 `domain/modules/web/furniture_web/static/`）：

- `render/furniture/desk_geometry.js`：圆角桌面由 `ExtrudeGeometry` 生成，提供 `seamPositions`，但 `geometry.index` 为 `null`。
- `render/outline/wall_contact.js`：曲面接触分支以 `seamPositions` 判断是否检测三角面，直接使用 `index.count` 与 `index.getX()`。

复现条件：墙体只接触桌面侧面的中间高度，上下包边都不接触该墙块。可以用上下两个窗洞之间的剩余墙带构造；该墙带让检测进入三角面分支。

最小几何配置：

1. 使用 `addDesk()` 创建宽 1200、深 600、高 750 mm、`z_start: 0` 的桌子，足迹为 `[[0,0],[1200,0],[1200,600],[0,600]]`。
2. 实际桌面高度范围为 726–750 mm，中间高度为 738 mm。
3. 用 `wallSolids(1200, 1000, 2800, openings)` 创建北墙。两个窗洞均从横向 0 开始、宽 1200 mm：下洞高度 736 mm、窗台 0；上洞窗台 740 mm、高度 2060 mm。中间保留 736–740 mm 的墙带。
4. 将北墙的 `boxes` 经 `wallGeometry()` 加入同一根节点，相机启用 `ROOM_LAYER`，调用 `createWallContactUpdater()([root], camera)`。

当前结果：`TypeError: Cannot read properties of null (reading 'count')`，本次绘制在准备阶段中断。

完成条件：

- 三角面遍历正确处理有索引和无索引网格；不能仅跳过无索引网格来隐藏错误，否则会漏掉真实接触。
- 用真实圆角桌面与窄墙带验证不抛错且识别接触，移离后恢复。
- 保留现有软包曲面、接触包边、门窗洞口及接地行为，并将回归用例接入统一检查。

## 待修：蒙版扩边越过前景遮挡边缘

涉及文件：`domain/modules/web/furniture_web/static/render/outline/cartoon_outline.js`。不透明实体在颜色和身份蒙版中清空家具区域，但最终合成会从相邻家具像素扩边；目标像素没有家具身份时，不能据此判断它是背景还是前景遮挡实体。合成关闭深度测试，因此后方描边仍能画到前景实体表面。

最小 WebGL 配置（Three.js 坐标）：

1. 画布 600 × 400，DPR 1，正交相机范围 `[-300,300] × [-200,200]`，相机在 `(0,0,1000)` 朝原点。
2. 后方家具：`BoxGeometry(200,200,100)`，位于原点，颜色 `0xbbaa99`，注册家具身份及描边色 `0x28231d`。
3. 前景实体：`BoxGeometry(200,300,10)`，位于 `(-100,0,100)`，不透明、颜色 `0xe4ddcf`，不注册家具描边。
4. 按实际顺序执行 `prepare()` → 主场景绘制 → `draw()`；与同样执行 `prepare()`、但关闭最后合成的画面对比。

当前结果：画布从左上计的 `(298,200)`、`(299,200)` 位于前景实体内侧。打开合成后，RGB 从 `[228,221,207]` 变成 `[38,34,28]`，被后方家具的粗线覆盖。

完成条件：

- 最终扩出的轮廓服从前景实体遮挡，包含交界边缘；同时保留可见家具轮廓与不同家具之间的边界。
- 像素检查扫描遮挡交界的内外两侧，覆盖不透明实体、透明墙、前后深度顺序、DPR 1 / 2 及正交 / 透视视角。
- 将失败复现接入统一检查；原有同件接缝、不同家具交界、选中 / 碰撞颜色及接触消线继续通过。
